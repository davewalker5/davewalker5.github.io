ADS-B BaseStation Reader

Tracking, recording, and exploring aircraft movements from live ADS-B data

The ADS-B BaseStation Reader is a personal aircraft-observation project built around the capture, processing, storage, and visualisation of live ADS-B messages received from nearby aircraft.

The project combines a lightweight console tracker with a SignalR-based Tracker Hub and integrated user interface, providing live aircraft tracking, a radar-style spatial view, historical database browsing, and tools for examining and visualising recorded flight paths.

Configurable tracking profiles allow observations to be focused using criteria such as distance, altitude, and whether an aircraft is climbing, descending, or flying level, making it possible to adapt the same incoming data to different observational interests.

Developed incrementally over several years, the project brings together live observation, historical records, and exploratory analysis while retaining a modular architecture that can run across desktop systems and lightweight devices such as a Raspberry Pi.

The complete source code, documentation, configuration examples, and instructions for running the tracker are available in the GitHub repository.
