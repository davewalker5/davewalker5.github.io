RC2014

Applications and utilities for exploring a small, comprehensible Z80 computer

The programs described in this Field Note form part of my collection of software for the RC2014 Mini II.

The repository includes BASIC programs ranging from games and mathematical experiments to applications using the buttons and LEDs of the Digital I/O card.

It also contains supporting utilities, documentation, images and notes on transferring and running programs on the physical machine.

If you would like to explore the programs, see how they work or try them on an RC2014 of your own, everything is available in the GitHub repository.
