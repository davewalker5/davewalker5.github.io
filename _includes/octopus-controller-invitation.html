Octopus Controller

Exploring octopus-inspired distributed arm control, local sensing, and environmentally responsive movement

The arm movements shown throughout these investigations were generated using a simulation inspired by the unusual organisation of the octopus nervous system. Eight flexible arms operate with individual objectives and local control mechanisms, rather than having every movement prescribed centrally.

By assigning targets, adjusting arm parameters, and introducing food and obstacles, the simulation makes it possible to investigate reaching, local contact sensing, obstacle avoidance, grasping, and carrying. Reproducible scenarios allow several of these behaviours to be observed together.

The project is not intended as a detailed reconstruction of octopus anatomy or neurophysiology. It is an experiment in computational natural history: exploring how relatively simple local rules can contribute to complex, coordinated interactions with the environment.

The Python application, source code, documentation, and instructions for running the controller are provided in the GitHub repository. A browser-based version is also available as an interactive explorer.
